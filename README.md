# Trustody Feedback

This repository is the public place to report bugs and share feedback about [Trustody](https://trustody.finance), the multi-signature custody wallet. Trustody's source code is not published here; this repository contains no code and is used for issues only.

## Report a bug

[Open a new issue](https://github.com/TrustodyWallet/feedback/issues/new) and include:

- What you did, what you expected, and what happened instead
- The page or screen where it happened, and the exact error message if one was shown
- Your browser and device (for example, Chrome 142 on macOS, Safari on iPhone)
- The network involved (Bitcoin, Ethereum, Tron, Internet Computer, …), if any
- Screenshots, if they help

Please search [existing issues](https://github.com/TrustodyWallet/feedback/issues) first and add to an existing one if it describes the same problem.

## Suggest a feature

Open an issue describing the problem you want solved and how you would use the feature. Concrete examples help us most.

## Never share secrets

Issues are public. **Never post your recovery phrase, approval PIN, passkey or security key details, private keys, or anything that could give access to a wallet.** Trustody staff will never ask for them. Wallet IDs, transaction hashes and public addresses are fine to share when they help.

## Security vulnerabilities

Do not report security vulnerabilities in public issues. Email [support@trustody.finance](mailto:support@trustody.finance) with the details instead, and we will respond privately.
